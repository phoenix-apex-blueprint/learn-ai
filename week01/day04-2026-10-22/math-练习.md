## Python 验证

```python
import numpy as np
a = np.array([1, 0]); b = np.array([1, 1])
cos = np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))
print(cos)                 # 应约为 0.707
print(np.degrees(np.arccos(cos)))   # 应约为 45.0
```
