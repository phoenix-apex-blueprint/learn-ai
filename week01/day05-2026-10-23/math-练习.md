## 第 4 题（numpy 三行验证）

把第 1–3 题各用三行 numpy 验证（np.dot + np.linalg.norm）：

```python
import numpy as np
def cos_sim(v1, v2):
    return np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))

print(cos_sim([1, 1], [1, 0]))    # 应约为 0.707
print(cos_sim([2, 3], [4, 6]))    # 应为 1.0
print(cos_sim([1, 0], [-2, 0]))   # 应为 -1.0
```
